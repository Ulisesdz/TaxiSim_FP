## Descripción del proyecto  
Taxi Simulator es un videojuego desarrollado en Unity que combina mecánicas de simulación y conducción. En este juego, los usuarios pueden experimentar la vida de un taxista, recolectando clientes y completando sus trayectos dentro de una ciudad llena de desafíos. Además, el juego incluye un modo adicional de carrera libre en la autopista para poner a prueba las habilidades de conducción contrarreloj.  

## Características principales  
- **Simulación de Taxi**: Recoge clientes, llévalos a su destino y gana puntos según el tiempo.  
- **Modo Libre/Carrera**: Circuito en la autopista para mejorar tus tiempos y disfrutar de la conducción sin distracciones.  
- **Sistema de puntos**: Obtén y administra puntos para recuperar la licencia de taxi o comprar vehículos en el mercado.  
- **Multas por exceso de velocidad**: Evita perder puntos cuando la policía detecte que superas los 70 km/h.  
- **Velocímetro interactivo**: Monitoriza la velocidad para mantener el control y evitar multas.  
- **Gestión de NPCs**: Vehículos y peatones generados de forma dinámica para dar vida a la ciudad.  
- **MusicManager**: Sonidos y música ambiental que varían según las escenas y acciones del jugador.  

## Controles  
- **W/A/S/D o flechas direccionales**: Control de movimiento del taxi.  
- **Barra espaciadora**: Frenada en seco y derrape.  

## Requisitos del sistema  
- Desarrollado en Unity 2022.3.44f1  
- Sistema operativo: Windows, macOS o Linux  
- Git con soporte para Git LFS (Large File Storage)  

## Estructura del proyecto  
- **Assets/**: Contiene los prefabs, scripts, managers, y otros recursos del juego.  
- **Scripts/**: Lógica del juego, incluyendo controladores de cámara, managers, y factorías.  
- **Scenes/**: Diferentes escenas del juego, como la ciudad, la autopista y el menú principal.  
- **README.md**: Documento de presentación del repositorio.  
- **.gitignore**: Archivos y carpetas ignorados por Git.  
- **Git LFS**: Para gestionar archivos grandes como assets de la ciudad y la autopista.
